# ASCEND Development Instructions

Project Name: ASCEND

ASCEND is a premium fitness platform inspired by Apple, Nike and Notion.

Tech Stack:
- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage
- GitHub
- Vercel

Rules:

1. Never redesign the UI unless asked.
2. Never rewrite the whole project.
3. Modify only the files necessary.
4. Preserve all existing functionality.
5. Keep JavaScript modular.
6. Never remove animations.
7. Never remove comments.
8. Explain every change before making it.
9. Always keep code readable.
10. Avoid duplicate functions.
11. Never break Git compatibility.
12. Never change file names unless requested.
13. Keep performance optimized.
14. Preserve Apple/Nike premium design language.
15. Test logic before suggesting completion.

Coding Style:
- Small functions
- Modular architecture
- Clear comments
- ES6 syntax
- Consistent formatting
