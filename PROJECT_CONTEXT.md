# ASCEND Project Context

## Overview

ASCEND is a premium fitness platform inspired by Apple, Nike and Notion.

The goal is to build a real-world fitness application with clean architecture, modular code, beautiful UI and long-term scalability.

---

## Engineering Rules

- Never rewrite working code.
- Modify only the minimum necessary files.
- Preserve all existing functionality.
- Maintain backwards compatibility.
- Prefer modular architecture.
- Never duplicate logic.
- Reuse existing modules whenever possible.
- Explain your implementation plan before editing.
- Wait for user approval before writing code.

## Coding Standards

Keep functions small.

Document public APIs.

Avoid unnecessary DOM queries.

Avoid duplicate event listeners.

Avoid unnecessary timers.

Never hardcode configurable values.

Use localStorage only through dedicated modules.

Preserve the Apple/Nike visual language.

Every new feature must integrate with existing systems instead of creating new ones.
